# VideoSoon (VisionSeek) - 影視廣告微鏡頭靈感對焦庫

> 專為影視導演、廣告企劃、剪輯師打造的下一代 AI 動態視覺靈感與客戶對焦工具。

---

## 🌟 核心功能特色

1. **自然語言畫面搜尋**：「描述你要的畫面，一句就好 —— 把腦袋中的畫面打出來」。
2. **秒級微鏡頭切片循環**：每個鏡頭僅 2~4 秒（如 `00:24-00:26`），滑鼠懸停即時流暢循環播放。
3. **情境細分標籤**：
   - 搜尋「兩個人在交手」：細分為 **拳擊肉搏、武術劍道對招、特工近身擒拿、幽默慢動作交手、雙車機械交手**。
   - 搜尋「牽手」：細分為 **背對背牽手、餐桌上牽手、水裡牽手、男生主動牽手、內斂的牽手**。
4. **高級篩選側欄（完美還原專業影視規格）**：
   - 描述搜索開關、可下載切換、分鏡畫布開關
   - 分類（廣告片、宣傳片、豎屏廣告、AIGC、紀錄片）
   - 分級 [VIP]（編輯精選、全球精選、分類精選）
   - 畫幅（橫屏 / 豎屏）、地區（歐美、日本、韓國、泰國、內地港澳台）、年份、清晰度（2K/4K）
5. **分鏡畫布 / 導演提案對焦板 (Storyboard Canvas)**：
   - 卡片右下角「+」號一鍵收藏鏡頭。
   - 統計提案時長，支援「一鍵導出客戶提案版 (PDF/分享)」。

---

## 🚀 啟動方式 (本機 0 元運行)

在專案目錄下執行：

```bash
python3 server.py
```

打開瀏覽器訪問：
👉 **http://localhost:8765**
